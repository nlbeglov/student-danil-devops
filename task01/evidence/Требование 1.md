# Требование 1
> На VPS развернуть Gitea, PostgreSQL и Caddy через Docker Compose. Настроить домен, действующий HTTPS и перенаправление с HTTP. Открытая регистрация пользователей должна быть отключена.

## Подготовка VPS и запуск
Docker, файрвол (снаружи 22, 80, 443) — [common/prepare-vps.sh](../../common/prepare-vps.sh). HTTPS и перенаправление с HTTP обслуживает общий Caddy ([common/caddy](../../common/caddy/Caddyfile), блок `a1.fdghyt.com`), Gitea и PostgreSQL запускает проект Compose из [configs/](../configs/docker-compose.yml):
```bash
cd /opt/devops/task01/configs
cp .env.example .env && nano .env     # DOMAIN=a1.fdghyt.com
../scripts/setup-secrets.sh           # пароль PostgreSQL → .env и secrets/credentials.txt
docker compose up -d
../scripts/seed.sh                    # пользователи и репозиторий demo (требование 2)
```
Регистрация отключена переменной `GITEA__service__DISABLE_REGISTRATION=true` в [docker-compose.yml](../configs/docker-compose.yml), порты 80/443 опубликованы только у общего Caddy.
