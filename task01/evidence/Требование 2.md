# Требование 2
## 1. Создаем пользователей
```
docker compose exec -u git server gitea admin user create \
  --username review-admin \
  --email review-admin@politblocks.com \
  --admin \
  --random-password | tee -a /opt/task-01/credentials.txt
  --must-change-password=false
docker compose exec -u git server gitea admin user create \
  --username review-user \
  --email review-user@politblocks.com \
  --random-password | tee -a /opt/task-01/credentials.txt
  --must-change-password=false
```
(после этих команд пароли для пользователей можно будет найти в `/opt/task-01/credentials.txt`)
## 2. Создание репозитория и 2 коммита 
Создание репозитория произошло через веб-морду Gitea.
### Команды на macos (локально)
```
git init
git config user.name "review-user"
git config user.email "review-user@politblocks.com"
echo "# demo" > README.md
git add README.md
git commit -m "Initial commit"
printf 'gitea-test-v1\n' > check.txt
git add check.txt
git commit -m "Add check.txt"
cat -e check.txt
git remote add origin https://git.politblocks.com/review-user/demo.git
git push -u origin main
```
### Проверка коммита
```
git log -1 --format="%H"
git log --oneline
```
### Вывод
```
git log -1 --format="%H"
3c7bc3b218b336b11f43ac898848f1726656ee64
git log --oneline
3c7bc3b (HEAD -> main, origin/main) Add check.txt
26e7160 Initial commit
```
