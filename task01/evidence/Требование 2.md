# Требование 2
> Создать администратора review-admin и обычного пользователя review-user. От имени review-user создать закрытый репозиторий demo с двумя коммитами. Файл check.txt в последнем коммите содержит строку gitea-test-v1 и перевод строки LF. Записать полный hash коммита.

## Ход работы
Пользователей, репозиторий и коммиты создаёт [seed.sh](../scripts/seed.sh): пользователи через `gitea admin user create` (пароли генерируются в `secrets/credentials.txt`), репозиторий `demo` (`private: true`) через API, два коммита (`README.md`, затем `check.txt` через `printf 'gitea-test-v1\n'`) по HTTPS от имени `review-user`. Hash и SHA-256 сохраняются в [baseline.txt](baseline.txt). Дополнительные пользователи создаются интерактивно скриптом [user-create.sh](../scripts/user-create.sh).
