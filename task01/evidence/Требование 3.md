# Требование 3
> Проверить clone и push по HTTPS с правами обычного пользователя. Без авторизации закрытый репозиторий недоступен. Снаружи VPS доступны только SSH и порты 80/443; PostgreSQL работает во внутренней сети Compose.
## 1. Проверка **clone**
### Команда:
```
git clone https://git.politblocks.com/review-user/demo.git demo-clone
```
### Вывод:
```

remote: Compressing objects: 100% (3/3), done.
remote: Total 6 (delta 0), reused 0 (delta 0), pack-reused 0 (from 0)
Receiving objects: 100% (6/6), done.
```
