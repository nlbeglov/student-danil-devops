# Требование 3
> Проверить clone и push по HTTPS с правами обычного пользователя. Без авторизации закрытый репозиторий недоступен. Снаружи VPS доступны только SSH и порты 80/443; PostgreSQL работает во внутренней сети Compose.

## Clone, push, анонимный доступ (06.10.2026)
```
$ git clone https://review-user:***@a1.fdghyt.com/review-user/demo.git
$ git push origin HEAD
To https://a1.fdghyt.com/review-user/demo.git
   7239eeb..5cc49ae  HEAD -> main

$ curl -sI https://a1.fdghyt.com/review-user/demo | head -1
HTTP/2 404
$ git ls-remote https://a1.fdghyt.com/review-user/demo.git
fatal: could not read Username for 'https://a1.fdghyt.com': No such device or address
```

## Порты снаружи
Проверка с другого сервера (130.17.27.121), так как сеть рабочего компьютера принимает соединение на любой порт и `nc` там даёт ложный «succeeded»:
```
port 22: open
port 80: open
port 443: open
port 3000: closed/timeout
port 5432: closed/timeout

$ curl --max-time 5 http://a1.fdghyt.com:3000/   ->  Connection timed out
$ curl --max-time 5 http://a1.fdghyt.com:5432/   ->  Connection timed out
```
В compose у `db` и `server` нет опубликованных портов (`5432/tcp`, `3000/tcp` только внутри сети), снаружи слушает общий Caddy на 80/443.
