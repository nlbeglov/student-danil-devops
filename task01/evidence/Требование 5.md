# Требование 5
> Восстановить сервис в отдельном проекте Compose с новыми томами. Допускается тот же VPS. Для проверки использовать отдельный адрес либо локальный порт через SSH-туннель. Восстановленный проект должен работать при остановленном исходном проекте.

## Ход работы
[restore.sh](../scripts/restore.sh) создаёт отдельный проект `task01-restore` в новом каталоге (`/opt/task01-restore`) с новыми каталогами данных, расшифровывает архив, восстанавливает дамп `pg_restore` и файлы Gitea. Копия публикуется на отдельном адресе `danil1.fdghyt.com`: у сервиса копии в сети `edge` своё имя (`task01-restore-gitea`), на которое указывает блок `DOMAIN_TASK01_RESTORE` общего Caddy.

```bash
cd /opt/devops/task01/configs && docker compose stop        # исходный проект остановлен
cd .. && RESTORE_DOMAIN=danil1.fdghyt.com ./scripts/restore.sh task01-restore /opt/task01-restore backups/backup-2026-10-06_0112.tar.gz.gpg files
./scripts/check.sh /opt/task01-restore files
```
