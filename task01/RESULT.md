## 5. Проверка за 5 минут
1. `curl -I https://git.politblocks.com/review-user/demo` — ожидается `HTTP 404` (анонимный доступ закрыт).
2. Войти под `review-user`, открыть репозиторий `demo`, убедиться в наличии `check.txt` со строкой `gitea-test-v1`.
3. `git clone https://git.politblocks.com/review-user/demo.git` и сравнить hash последнего коммита: `git log -1 --format="%H"` → должен совпасть с финальным коммитом.
4. Остановить исходный проект (`docker compose stop`) и поднять восстановленную копию — убедиться, что она отвечает и содержит тот же коммит.

Ожидаемый результат:
- Приватный репозиторий недоступен без авторизации (404).
- Пользователь входит, видит `demo` с двумя коммитами.
- Hash в восстановленной копии совпадает с исходным.
## Проблемы и ограничения
- `scripts/backup.sh` в текущем виде дублирует содержимое `restore.sh` (ошибка при подготовке архива) и требует пересборки по логике, описанной в `evidence/Требование 4.md`.
- Проверка автозапуска контейнеров после перезагрузки VPS (`check.sh`, шаг 2/6) выполняется вручную — сравнение времени старта с временем загрузки системы не автоматизировано.
- `configs/Caddyfile` при восстановлении на другом домене нужно править вручную (домен захардкожен).
