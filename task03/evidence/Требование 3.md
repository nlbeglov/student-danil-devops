# Требование 3
> Снимать дамп через pg_dump и копировать файлы при остановленных тестовых записях. Дамп, файлы и необходимые настройки сохранять через restic в зашифрованный репозиторий вне VPS: SFTP либо объектное хранилище.

## Ход работы
1. Доступ VPS к внешнему SFTP-хранилищу без пароля настраивает [setup-storage.sh](../scripts/setup-storage.sh): отдельный ключ `~/.ssh/task03_restic_key` (приватная часть остаётся только на VPS), запись в `~/.ssh/config`, публичная часть копируется на хранилище.
2. Ключ шифрования репозитория `RESTIC_PASSWORD` создаёт [setup-secrets.sh](../scripts/setup-secrets.sh) в `secrets/credentials.txt` (вне git, передаётся отдельно).
3. [restic-init.sh](../scripts/restic-init.sh) инициализирует репозиторий (повторный запуск безопасен).
4. [backup.sh](../scripts/backup.sh): запись в БД блокируется (`default_transaction_read_only = on` для новых подключений) → `pg_dump -F c` → `restic backup` дампа, каталога `data/files`, настроек (без пароля БД) → запись разрешается → `restic forget --keep-last 3 --prune`.
