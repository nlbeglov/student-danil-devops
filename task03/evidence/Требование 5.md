# Требование 5
> Проверить внешний репозиторий. Удалить временный локальный дамп и каталог сборки копии, остановить исходный проект. Получить копию из внешнего хранилища и восстановить БД и файлы в отдельный проект Compose с новыми томами. Исходные тома сохранить.

## Ход работы
[restore.sh](../scripts/restore.sh): проверяет, что исходный проект остановлен → удаляет `data/backup-tmp` → `restic snapshots` и `restic check` → `restic restore latest` во временный каталог → собирает проект `task03-restore` с новыми каталогами `restore/data/postgres` и `restore/data/files` и новым паролем БД → `pg_restore` → запускает Caddy. Для работы нужны только доступ к хранилищу и `RESTIC_PASSWORD`; исходные тома (`data/`) не трогаются.

```bash
cd /opt/devops/task03
(cd configs && docker compose stop)            # исходный проект остановлен
./scripts/restore.sh                           # каталог по умолчанию: ./restore
# если исходного проекта на VPS уже нет:
# RESTIC_REPOSITORY=sftp:user@host:/path RESTIC_PASSWORD=<ключ> ./scripts/restore.sh /opt/task03-restore
```
Фактический вывод и время восстановления: _приложить после запуска на VPS_.
