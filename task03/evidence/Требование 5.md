# Требование 5
> Проверить внешний репозиторий. Удалить временный локальный дамп и каталог сборки копии, остановить исходный проект. Получить копию из внешнего хранилища и восстановить БД и файлы в отдельный проект Compose с новыми томами. Исходные тома сохранить.

## Ход работы
[restore.sh](../scripts/restore.sh): проверяет, что исходный проект остановлен → удаляет `data/backup-tmp` → `restic snapshots` и `restic check` → `restic restore latest` во временный каталог → собирает проект `task03-restore` с новыми каталогами `restore/data/postgres` и `restore/data/files` и новым паролем БД → `pg_restore`. Для работы нужны только доступ к хранилищу и `RESTIC_PASSWORD`; исходные тома (`data/postgres`, `data/files`) не затрагиваются.

```bash
cd /opt/devops/task03/configs && docker compose stop     # исходный проект остановлен
../scripts/restore.sh
```
