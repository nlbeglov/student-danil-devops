# Требование 2
> Создать файлы a.txt, b.txt, c.txt со строками alpha, beta, gamma соответственно, каждый с окончанием LF. Скриптом подготовить исходный manifest: число строк, SHA-256 выгрузки таблицы в CSV с сортировкой по id и SHA-256 каждого файла. Сохранить формат выгрузки для повторного сравнения.

## Ход работы
Файлы и исходный manifest создаёт [prepare-data.sh](../scripts/prepare-data.sh) (один раз после старта БД и до первой копии). Файлы пишутся через `printf '...\n'`, чтобы окончание строки было ровно одним LF. Сразу после этого скрипт вызывает [manifest.sh](../scripts/manifest.sh) и сохраняет результат в [manifest-original.txt](manifest-original.txt): с ним [check.sh](../scripts/check.sh) сравнивает manifest восстановленного проекта обычным `diff`. Формат одинаков при каждом запуске; сортировка `ORDER BY id` обязательна, иначе порядок строк, а с ним и SHA-256, не гарантированы.
