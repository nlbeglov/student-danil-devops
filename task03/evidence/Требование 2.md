# Требование 2
> Создать файлы a.txt, b.txt, c.txt со строками alpha, beta, gamma соответственно, каждый с окончанием LF. Скриптом подготовить исходный manifest: число строк, SHA-256 выгрузки таблицы в CSV с сортировкой по id и SHA-256 каждого файла. Сохранить формат выгрузки для повторного сравнения.

## Ход работы
Файлы и исходный manifest создаёт [prepare-data.sh](../scripts/prepare-data.sh) (запускается один раз после старта БД и до первой копии). Файлы пишутся через `printf '...\n'`, чтобы окончание строки было ровно одним LF. Сразу после этого скрипт вызывает [manifest.sh](../scripts/manifest.sh) и сохраняет результат в `evidence/manifest-original.txt`: с ним [check.sh](../scripts/check.sh) сравнивает manifest восстановленного проекта обычным `diff`.

Формат manifest (одинаков при каждом запуске):
```
row_count=100
dump_sha256=<SHA-256 выгрузки: SELECT id, value FROM items ORDER BY id; в CSV>
a.txt=<SHA-256>
b.txt=<SHA-256>
c.txt=<SHA-256>
```
Сортировка `ORDER BY id` обязательна: без неё порядок строк не гарантирован и SHA-256 мог бы отличаться.

## Вывод скрипта
```bash
./scripts/prepare-data.sh && cat evidence/manifest-original.txt
```
