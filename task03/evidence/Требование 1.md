# Требование 1
> Развернуть PostgreSQL и выдачу тестовых файлов по HTTPS через Caddy. PostgreSQL доступен только внутри Compose. Создать таблицу items(id integer primary key, value text) со 100 строками: id от 1 до 100, value от item-001 до item-100.

## Файлы
- [.env.example](../configs/.env.example) — переменные, секреты `CHANGE_ME`;
- [docker-compose.yml](../configs/docker-compose.yml) — `postgres:14` без публикации порта, `caddy:2.11.4` на 80/443, данные в `../data/`;
- [Caddyfile](../configs/Caddyfile) — выдача каталога `data/files` по HTTPS (`file_server`);
- [01-items.sql](../configs/01-items.sql) — создаёт `items` и заполняет 100 строк (`generate_series`), выполняется один раз при первом старте на пустом томе.

## Запуск и проверка
```bash
cd /opt/devops/task03/configs
docker compose up -d      # после cp .env.example .env, заполнения .env и ../scripts/setup-secrets.sh
docker compose exec -T db psql -U lab -d lab -c "SELECT count(*), min(value), max(value) FROM items;"
docker compose ps --format '{{.Service}} {{.Ports}}'
curl -s https://files.example.com/a.txt
```
Ожидается: `count=100`, `item-001`, `item-100`; у `db` нет опубликованных портов; `alpha`.
