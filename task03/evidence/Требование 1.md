# Требование 1
> Развернуть PostgreSQL и выдачу тестовых файлов по HTTPS через Caddy. PostgreSQL доступен только внутри Compose. Создать таблицу items(id integer primary key, value text) со 100 строками: id от 1 до 100, value от item-001 до item-100.

## Файлы
- [.env.example](../configs/.env.example) — переменные, секреты `CHANGE_ME`;
- [docker-compose.yml](../configs/docker-compose.yml) — только `postgres:14` без публикации порта, данные в `../data/postgres`;
- [01-items.sql](../configs/01-items.sql) — создаёт `items` и заполняет 100 строк (`generate_series`), выполняется один раз при первом старте на пустом томе;
- HTTPS и выдачу `data/files` обслуживает общий Caddy ([common/caddy/Caddyfile](../../common/caddy/Caddyfile), блок `a3.fdghyt.com`, `file_server`).

## Запуск
```bash
cd /opt/devops/task03/configs
cp .env.example .env && nano .env      # DOMAIN=a3.fdghyt.com, RESTIC_REPOSITORY=sftp:root@130.17.27.121:/home/pop
../scripts/setup-secrets.sh
docker compose up -d
```
