> В последнем коммите создать check.txt со строкой diagnostics-test-v1 и окончанием LF. Зафиксировать полный hash коммита и SHA-256 файла. Сохранить исходную рабочую конфигурацию и показать, что после перезагрузки VPS данные и доступы сохраняются.
Первая часть требования 2 выполнена в [требовании 1](<Требование 1.md>)

## Перезагрузка VPS 
```
cd /opt/task05
./scripts/check.sh | tee evidence/reboot-before.txt
sudo reboot
```
Подождать минуту-две, зафйти снова
```
uptime -s
cd /opt/task05/configs && docker compose ps
cd /opt/task05 && ./scripts/check.sh | tee evidence/reboot-after.txt
```
Что должно быть видно: все три контейнера снова Up/healthy, время запуска контейнеров близко к времени загрузки системы, а check.sh проходит целиком, включая тот же hash коммита и ту же сумму check.txt.
