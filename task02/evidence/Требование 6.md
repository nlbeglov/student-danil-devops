# Требование 6
> Предусмотреть ручной запуск отката из GitHub Actions на ранее сохранённый digest версии A. Использовать готовый образ. После отката проверить /version, /health и сложение. Описать порядок следующего обычного выпуска.

## 1. Workflow отката
[.github/workflows/rollback.yml](../.github/workflows/rollback.yml) запускается вручную (`workflow_dispatch`) с полями `image_digest` и `app_version`. Формат проверяется до любых действий (`sha256:<64 hex>`, безопасные символы версии). В workflow **нет** job `build`: используется готовый образ `ghcr.io/<repo>@<digest>` и тот же `scripts/ci-deploy.sh`, что и при обычной доставке; та же группа `concurrency`.

## 2. Откат на версию A (06.10.2026)

## 3. Порядок следующего обычного выпуска
После отката в `main` остаётся ошибочный коммит, поэтому следующий выпуск — это новый коммит с исправлением: `git push` → тесты → сборка нового образа → доставка по новому digest. В прогоне это revert ошибочного коммита `9bbf434`: [CI/CD #8](https://github.com/nlbeglov/nerp-test-task02/actions/runs/37385324487), `test` ✅ → `build` ✅ → `deploy` ✅, новый digest `sha256:20c1dc13c5ed5ff22809b2aed480dbb927109d53d7cfe84965071d36aa3061c2`, `/version` = `9bbf43403d7ad70e096258e989cb951f75511d98`. Предыдущим выпуском для него записан digest A (после отката).
