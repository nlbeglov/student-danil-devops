## 2. Dockerfile, Compose, HTTPS
- [Dockerfile](../configs/Dockerfile) — `python:3.12.3-slim`, кэшируемый слой зависимостей отдельно от кода, версия образа фиксирована (не `latest`), `APP_VERSION` прошивается через `ARG`/`ENV`, старт через `gunicorn`.
- [docker-compose.yml](../configs/docker-compose.yml) — два сервиса, `app` без наружного порта (только внутри сети `task02`), `caddy:2.11.4` с HTTPS на 80/443.
- [configs/Caddyfile](../configs/Caddyfile) — `test0.politblocks.com { reverse_proxy app:8000 }`, Caddy сам получает сертификат Let's Encrypt.

Сервис не использует базу данных — состояние процесса не хранится, `APP_VERSION` приходит только из переменных окружения.
