## 2. Dockerfile, Compose, HTTPS
- [Dockerfile](../configs/Dockerfile) — `python:3.12.3-slim`, кэшируемый слой зависимостей отдельно от кода, версия образа фиксирована (не `latest`), `APP_VERSION` прошивается через `ARG`/`ENV`, приложение работает не от root, старт через `gunicorn`.
- [docker-compose.yml](../configs/docker-compose.yml) — сервис `app` без опубликованного порта (виден только в сети `edge` под именем `task02-app`), образ берётся по digest из `IMAGE_REF`.
- HTTPS на 80/443 обслуживает общий Caddy `caddy:2.11.4` ([common/caddy/Caddyfile](../../common/caddy/Caddyfile)): блок `a2.fdghyt.com { reverse_proxy task02-app:8000 }`, сертификат Let's Encrypt выпускается автоматически.

Сервис не использует базу данных — состояние процесса не хранится, `APP_VERSION` приходит только из переменных окружения.
