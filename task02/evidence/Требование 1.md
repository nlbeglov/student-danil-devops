# Требование 1
## 1. Репозиторий и сервис
Репозиторий: [github.com/nlbeglov/nerp-test-task02](https://github.com/nlbeglov/nerp-test-task02) (публичный).

Сервис — Flask, файл [src/app.py](../src/app.py):
- `GET /health` → всегда `200 {"status":"ok"}`.
- `GET /version` → `200 {"version": "<APP_VERSION>"}`, значение берётся из переменной окружения.
- `GET /add?a=&b=` → `200 {"result": a+b}` при целых `a`/`b`, иначе `400 {"error": "..."}` (параметр отсутствует или не целое число, включая дробные вроде `3.5`).
## 2. Локальный запуск и проверка
```
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 src/app.py
```
```
curl http://localhost:8000/health
curl http://localhost:8000/version
curl "http://localhost:8000/add?a=2&b=3"
curl "http://localhost:8000/add?b=3"
curl "http://localhost:8000/add?a=abc&b=3"
```
Вывод:
```
{"status":"ok"}
{"version":"dev"}
{"result":5}
{"error":"parametr 'a' is missing"}
{"error":"parametr 'a' must be an integer, got: 'abc'"}
```
## 3. Запуск в Docker
```
docker build --build-arg APP_VERSION=test-A -t task02-app:test .
docker run --rm -p 8000:8000 task02-app:test
```
```
curl http://localhost:8000/health
curl http://localhost:8000/version
curl "http://localhost:8000/add?a=2&b=3"
```
Вывод:
```
{"status":"ok"}
{"version":"test-A"}
{"result":5}
```
`APP_VERSION` в проде не захардкожен — приходит из `.env`/`docker-compose.yml` на сервере и равен SHA задеплоенного коммита (см. [Требование 3](<Требование 3.md>)).
