# Требование 1
> Разместить стенд на двух VPS. На первом развернуть Nginx с адресом /health и Caddy для HTTPS. На втором развернуть Uptime Kuma, ntfy и HTTPS для их интерфейсов. Составить отдельный Compose для каждого сервера.

## Схема
- VPS-A (цель, 130.17.27.121): Nginx с адресом `/health` (200 или 503) и свой Caddy для HTTPS — [target-vps/configs](../target-vps/configs/docker-compose.yml). Порт 443 на этом сервере занят другим сервисом, поэтому HTTPS цели работает на порту 8443 (`HTTPS_PORT` в `.env`).
- VPS-B (мониторинг, 144.31.119.139): Uptime Kuma и ntfy — [monitor-vps/configs](../monitor-vps/configs/docker-compose.yml); HTTPS обслуживает общий Caddy ([common/caddy](../../common/caddy/Caddyfile), домены `a5.fdghyt.com` и `a6.fdghyt.com`).
- Для каждого сервера свой Compose: `task04-target` и `task04-monitor`.

## Запуск
```bash
# VPS-A
cd /opt/devops/task04/target-vps/configs && cp .env.example .env && nano .env   # TARGET_DOMAIN=danil2.fdghyt.com, HTTPS_PORT=8443
../scripts/deploy-target.sh
# VPS-B
cd /opt/devops/task04/monitor-vps/configs && cp .env.example .env && nano .env  # KUMA_DOMAIN=a5.fdghyt.com, NTFY_DOMAIN=a6.fdghyt.com
../scripts/deploy-monitor.sh
../scripts/setup-secrets.sh
```
