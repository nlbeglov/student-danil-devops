# Требование 1
> Разместить стенд на двух VPS. На первом развернуть Nginx с адресом /health и Caddy для HTTPS. На втором развернуть Uptime Kuma, ntfy и HTTPS для их интерфейсов. Составить отдельный Compose для каждого сервера.
## Список стендов
1. Senko Digital (Хельсинки, Финляндия), 2 vCPU / 4 GB RAM / диск 60 GB.
2. Aeza (Хельсинки, Финляндия) 1 vCPU / 4 GB RAM / диск 10 G

Стенд 1 - мониторинг (monitor-vps)
Стенд 2 - цель (target-vps)
## Подготовка стендов
На обоих проверка докера
```
docker --version && docker compose version
sudo systemctl is-enabled docker
```
На обоих (в основном на стенде номер 2) проверка ufw
```
ufw status
# если выключены
sudo ufw allow OpenSSH && sudo ufw allow 80/tcp && sudo ufw allow 443/tcp
sudo ufw enable
```

Был создан скрипт [deploy-target.sh](../target-vps/scripts/deploy-target.sh), который готовит начальное состояние (up) до старта nginx

Запускаем стенд
