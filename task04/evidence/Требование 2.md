# Требование 2
> Подготовить scripts/set-health.sh up|down. В режиме up адрес /health возвращает HTTP 200, в режиме down — HTTP 503. Переключение выполнить изменением конфигурации Nginx и её корректной перезагрузкой; порт HTTPS остаётся доступным.

## Скрипт
[set-health.sh](../target-vps/scripts/set-health.sh) `up|down`: подменяет включаемый файл `state.inc` (шаблон `up.inc` — `return 200`, `down.inc` — `return 503`), проверяет конфигурацию (`nginx -t`), выполняет корректную перезагрузку (`nginx -s reload`, без перезапуска контейнера), пишет время в `set-health.log`, затем проверяет код ответа по HTTPS. Порт HTTPS остаётся доступным в обоих режимах.

## Результат (06.10.2026)
```
https://danil2.fdghyt.com:8443/health -> HTTP 503
воздействие: set-health down в 01:25:38
https://danil2.fdghyt.com:8443/health -> HTTP 200
воздействие: set-health up в 01:27:02
```
Нужный код (503 в режиме `down`, 200 в `up`) скрипт дожидается до 10 секунд; TCP-порт цели в режиме `down` остаётся открытым (`check.sh`: «TCP 8443 открыт»).
