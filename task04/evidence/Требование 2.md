# Требование 2
> Подготовить scripts/set-health.sh up|down. В режиме up адрес /health возвращает HTTP 200, в режиме down — HTTP 503. Переключение выполнить изменением конфигурации Nginx и её корректной перезагрузкой; порт HTTPS остаётся доступным.
## Подготовка скрипта scripts/set-health.sh up|down
Этот [скрипт](../target-vps/scripts/set-health.sh) будет переключать /health между 200 и 503, обновлять state.inc, проверять конфиг, делать reload и писать время подключения в журнал

Включаем скрипт на состояние 503, проверяем вывод, проверяем что порт HTTPS остаётся доступным, переключаем на состояние 200 
```
cd /opt/task04-target
./scripts/set-health.sh down
nc -zv test3.politblocks.com 443
./scripts/set-health.sh up
```
