# Требование 4
> Доставлять сообщения через собственный ntfy в браузер или на телефон. Включить авторизацию ntfy и закрыть анонимную публикацию и чтение тестового канала. Интерфейс Uptime Kuma также защитить входом. Секреты подключения хранить вне архива исходных файлов.
## Пользователи и права ntfy
Схема доступа (принцип минимальных прав)
| пользователь | роль | назначение |
| --- | --- | --- |
| admin | admin | для управления и входа в веб-клиент |
| reader | read-only | для браузера и ntfy-history.sh |
| kuma | write-only | публикация уведомлений |
| анонимный | deny-all | запрет доступа без логина |

Создаем скрипт [setup-secrets.sh](../monitor-vps/scripts/setup-secrets.sh), который создает все пароли стенда (пользователи ntfy и администратор Kuma), показывает их на экране и сохраняет в secrets/credentials.txt, чтобы к ним можно было вернуться в любой момент. 

> [!note]
> После запуска скрипта необходимо зайти на сайт KUMA_URL и воучную создать администратора

Проверка анонимного доступа
```
# чтение без логина → 401/403
curl -s -o /dev/null -w 'anon read:  %{http_code}\n' "https://test1.politblocks.com/monitor-alerts/json?poll=1"
# публикация без логина → 401/403
curl -s -o /dev/null -w 'anon write: %{http_code}\n' -d "anon-test" "https://test1.politblocks.com/monitor-alerts"
# чтение под reader → 200; публикация под reader → 403 (только чтение)
curl -s -o /dev/null -w 'reader read:  %{http_code}\n' -u reader "https://test1.politblocks.com/monitor-alerts/json?poll=1"
curl -s -o /dev/null -w 'reader write: %{http_code}\n' -u reader -d "x" "https://test1.politblocks.com/monitor-alerts"
```
Вывод:
```
anon read:  403
anon write: 403
Enter host password for user 'reader':
reader read:  200
Enter host password for user 'reader':
reader write: 403
```
## Клиент ntfy
Вход в клиента для отслеживания уведомлений. Проверяем здесь резултаты тестов из [Требования 3](<Требование 3.md>)
- В браузере открываем https://test1.politblocks.com/  
- Заходим под пользователем reader
- Subscribe to topic - `monitor-alerts`
- По желанию: разрешить уведомления от сайта
