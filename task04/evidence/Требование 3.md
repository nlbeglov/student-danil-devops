# Требование 3
> В Uptime Kuma добавить HTTP-проверку /health, принимающую только код 200, и отдельную TCP-проверку порта 443 первого VPS. Интервал — 30 секунд. Настроить уведомления о переходах DOWN и UP; сообщение должно содержать имя проверки и состояние.
## Uptime Kuma: вход, уведомление, два монитора
> [!note]
> Первый вход в Uptime Kuma, создание паролей и клиент ntfy описано в [Требовании 4](<Требование 4.md>)
Всё делается в веб-интерфейсе KUMA_URL=https://test0.politblocks.com
### Настройка уведомлений через ntfy
Переходим в Settings - Notifications - Setup Notification

И устанавливаем следующие настройки:

![Setup Notification](<Снимок экрана 2026-10-02 в 00.03.44.png>)

### Настройка мониторов
Необходимо создать два монитора со следующими настройками:
| Поле | Значение монитор 1 | Значение монитор 2 |
|---|---|---|
| Monitor Type | HTTP(s) | TCP Port |
| Friendly Name | target-http-health | target-tcp-443 |
| URL | https://test3.politblocks.com/health | - |
| Hostname | - | test3.politblocks.com |
| Port | - | 443 |
| Heartbeat Interval | 30 | 30 |
| Retries | 0 | 0 |
| Accepted Status Codes | 200 | - |
| Notifications | ntfy-own on | ntfy-own on |
