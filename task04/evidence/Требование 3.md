# Требование 3
> В Uptime Kuma добавить HTTP-проверку /health, принимающую только код 200, и отдельную TCP-проверку порта 443 первого VPS. Интервал — 30 секунд. Настроить уведомления о переходах DOWN и UP; сообщение должно содержать имя проверки и состояние.

## Уведомление и мониторы
Уведомление `ntfy-own` (тип ntfy, топик `monitor-alerts`, авторизация пользователем `kuma`, включено по умолчанию) и два монитора с интервалом 30 с созданы в Uptime Kuma. Параметры из `kuma.db` без секретов (06.10.2026):
```
{"id":1,"name":"target-http-health","type":"http","url":"https://danil2.fdghyt.com:8443/health","hostname":null,"port":null,"interval":30,"maxretries":0,"accepted_statuscodes_json":"[\"200\"]"}
{"id":2,"name":"target-tcp-8443","type":"port","url":"https://danil2.fdghyt.com:8443/","hostname":"danil2.fdghyt.com","port":8443,"interval":30,"maxretries":0,"accepted_statuscodes_json":"[\"200-299\"]"}
{"id":1,"name":"ntfy-own","is_default":1,"t":"ntfy","url":"https://a6.fdghyt.com","topic":"monitor-alerts","auth":"usernamePassword","u":"kuma"}
```
HTTP-монитор принимает только код `200` (`accepted_statuscodes_json: ["200"]`), TCP-монитор проверяет порт 8443 цели (HTTPS-порт VPS-A). Сообщение ntfy содержит имя проверки и состояние (`target-http-health Down [Uptime-Kuma]`). Поле `url` у TCP-монитора заполнено намеренно: без него Kuma 1.23 отправляет в ntfy кнопку без адреса, и ntfy отвечает 400.
